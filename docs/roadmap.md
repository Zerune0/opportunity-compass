# Implementation roadmap
This is a proposed sequence, not a delivery schedule or completed work. The full frozen product scope remains in product-scope.md.

1. Define source-backed records, uncertainty states, synthetic fixtures and acceptance criteria.
2. Build one student journey: discovery → requirement explanation → constraints → candidate routes → evidence update → application plan.
3. Add multi-opportunity material reuse, recovery paths, recommendation replay and accessible Adventure/Classic views.
4. Connect organizer scenarios to shared allocation, coverage protection and fairness constraints; verify candidates independently.
5. Add trusted publishing and consent-based matching with field-level visibility and abuse handling.
6. Compare baselines, conduct controlled fairness checks, then collect voluntary user feedback and distinguish it from simulation.

When this was written no milestone was complete. Since then, parts of steps 1–4 have been built for the competition scope (see README "Project status"); steps 5–6 are not built. Choose the implementation stack with the team before adding dependencies. Do not generate mock success metrics or represent sample opportunities as verified live listings.
