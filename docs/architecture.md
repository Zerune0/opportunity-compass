# Proposed architecture
Status: design boundaries only; no stack or implementation commitment.

Student Compass is the main interface. Discovery retains source text, official URL, retrieval/verification dates and uncertainty. Eligibility evaluates individual rules; readiness records preparation; reachability checks real constraints. Pathways proposes and compares target-linked tasks. Evidence updates drive explicit recommendation replay. Applications coordinates deadlines and material reuse.

Organizer Intelligence supplies approved or hypothetical intervention scenarios to the same shared resource model. Shared allocation must prevent multiple routes from spending the same funds, equipment or time slot.

The independent verifier must check candidate plans without relying solely on the optimizer's own feasibility flag. AI can help extract and explain information and suggest candidates; source verification, deterministic rules, tested constraint checks and user choice govern decisions.

Proposed records: Opportunity, SourceRecord, Requirement, StudentProfile, EvidenceItem, Quest, Path, ApplicationPlan, Intervention, ResourceAllocation, DecisionReplay and ValidationResult. Schemas, interfaces, storage, authentication, frameworks and solver selection remain to be designed.
